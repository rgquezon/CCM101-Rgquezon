# Mission 1: Welcome to the Cloud

## Mission Overview
This mission serves as an onboarding activity to get familiar with working inside a cloud-based Linux environment and maintaining a version-controlled repository on GitHub.

## Objectives
* Access a cloud-based Linux environment using KillerCoda.
* Explore and navigate the Linux operating system.
* Gather basic system information.
* Organize files and directories using Linux commands.
* Create and maintain a professional GitHub repository.

## Activities Performed
* Created a new Linux user with sudo privileges and logged in.
* Gathered system hardware and OS specs using terminal commands.
* Created a structured workspace directory (`Documents`, `Notes`, `Reports`, `Screenshots`).
* Set up a public GitHub repository and organized lab folders.

## Linux Commands Used
* `useradd`, `passwd`, `usermod`, `su`
* `whoami`, `pwd`, `hostname`
* `cat /etc/os-release`, `uname -r`, `lscpu`, `free -h`, `df -h`
* `mkdir`, `ls`, `cd`, `cp`, `touch`
* `nano`

## Skills Learned
Learned basic Linux file system navigation, user account management, terminal text editing, and Git workflow integration.
