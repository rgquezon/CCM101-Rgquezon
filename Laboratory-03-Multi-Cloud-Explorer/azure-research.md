# Microsoft Azure Research Report

## Brief Overview
Launched in 2010 by Microsoft, Azure is a leading cloud platform designed with deep integration for enterprise software and hybrid cloud architectures.

## Global Infrastructure
Azure has a vast global presence spanning over 60 regions worldwide, interconnected by Microsoft’s private fiber network and supported by Availability Zones for high availability.

## Cloud Management Console
The Azure Portal is a unified web-based graphical interface that organizes resources into customizable dashboards and Resource Groups for simplified administrative management.

## Four (4) Core Services
* **Compute:** Azure Virtual Machines
* **Storage:** Azure Blob Storage
* **Networking:** Azure Virtual Network (VNet)
* **Identity:** Microsoft Entra ID (formerly Azure Active Directory)

## Three (3) Key Advantages
1. **Native Microsoft Integration:** Seamless setup for organizations using Windows Server, Active Directory, and Microsoft 365.
2. **Strong Hybrid Capabilities:** Robust hybrid infrastructure solutions like Azure Arc and Azure Stack.
3. **Enterprise Compliance:** High degree of global regulatory and security compliance standards.

## Typical Enterprise Use Cases
* Migration of existing enterprise Windows Server and SQL environments.
* Hybrid cloud architectures extending on-premises Active Directory.
* Enterprise application development using .NET framework.
