## Guide Questions

**1. Which cloud provider offers the broadest range of services?**
Amazon Web Services (AWS) offers the broadest and most comprehensive range of cloud services available today. Due to being the first major public cloud platform, AWS has developed the deepest ecosystem, offering hundreds of fully featured services across compute, storage, databases, machine learning, and IoT.

**2. Which provider best integrates with Microsoft technologies?**
Microsoft Azure provides the best integration for organizations that rely on Microsoft technologies. It natively syncs with Windows Server, Active Directory (Entra ID), Office 365, and SQL Server, making hybrid cloud migration seamless for enterprise Windows environments.

**3. Which provider is strongest in Artificial Intelligence and Kubernetes?**
Google Cloud Platform (GCP) is widely recognized as the leader in Artificial Intelligence, Machine Learning, and Kubernetes. GCP created Kubernetes (derived from their internal Borg system) and TensorFlow, offering deeply optimized services like Google Kubernetes Engine (GKE) and Vertex AI.

**4. Which cloud platform would you personally choose and why?**
I would personally choose Google Cloud Platform (GCP) because of its developer-friendly interface, industry-leading container orchestration with GKE, and strong focus on data analytics and AI. Its clean dashboard and project-based architecture make managing cloud infrastructure streamlined and efficient.
