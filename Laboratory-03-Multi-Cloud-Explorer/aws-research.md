# Amazon Web Services (AWS) Research Report

## Brief Overview
Launched in 2006 by Amazon, Amazon Web Services (AWS) is a pioneer and leading public cloud platform. It offers an extensive array of cloud infrastructure and platform services globally.

## Global Infrastructure
AWS operates across a global footprint consisting of Geographic Regions, Availability Zones (AZs), Local Zones, and Edge Locations connected by a high-speed backbone network.

## Cloud Management Console
The AWS Management Console is a web-based portal providing direct access to manage cloud resources, configure security through IAM, monitor billing, and deploy infrastructure services.

## Four (4) Core Services
* **Compute:** Amazon Elastic Compute Cloud (EC2)
* **Storage:** Amazon Simple Storage Service (S3)
* **Networking:** Amazon Virtual Private Cloud (VPC)
* **Identity:** AWS Identity and Access Management (IAM)

## Three (3) Key Advantages
1. **Market Leadership & Broadest Service Catalog:** Offers the deepest selection of specialized cloud tools.
2. **Global Reach & Scalability:** Highly available multi-region architecture for elastic expansion.
3. **Extensive Ecosystem & Community:** Massive library of documentation, third-party integrations, and community support.

## Typical Enterprise Use Cases
* Enterprise web application hosting and global distribution.
* Big data analytics and data lake creation using S3 and Redshift.
* Automated backup, disaster recovery, and hybrid storage migration.
