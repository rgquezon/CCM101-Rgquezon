# Mission Reflection

### 1. Which cloud infrastructure component do you think is the most important? Why?
Among the core cloud infrastructure components, I believe **Compute** is the most vital. Compute resources provide the fundamental processing power required to run operating systems, execute code, process backend logic, and serve applications to end users. While storage holds data and networking enables connectivity, neither can deliver functional value without compute capacity actively driving the workloads.

### 2. How does Linux support cloud computing?
Linux serves as the foundational operating system of modern cloud infrastructure due to its open-source flexibility, lightweight resource footprint, strong security model, and high stability. Most cloud providers, virtualized instances, and containerization technologies (such as Docker and Kubernetes) rely natively on the Linux kernel. Its powerful command-line interface enables automated system administration and seamless scalability at scale.

### 3. Why is technical documentation important before deploying infrastructure?
Creating technical documentation before deployment provides a structured architectural blueprint. It allows engineering teams to evaluate resource requirements, security posture, and cost estimates before committing resources. Pre-deployment documentation reduces configuration mistakes, minimizes system downtime, prevents unnecessary costs, and establishes standard operating procedures for disaster recovery and team collaboration.

Through this activity, I gained practical experience using Linux CLI utilities to inspect hardware specifications like RAM, CPU architecture, and storage mount points. Additionally, I learned how to map physical server metrics to cloud service categories, compare equivalent infrastructure offerings across AWS, Azure, and GCP, and visualize multi-tier cloud architectures using diagramming tools.
