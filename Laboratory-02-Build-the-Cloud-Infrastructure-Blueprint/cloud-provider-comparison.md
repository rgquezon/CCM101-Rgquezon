# Major Cloud Providers Comparison

## Cloud Infrastructure Services Table

| Infrastructure Component | Amazon Web Services (AWS) | Microsoft Azure | Google Cloud Platform (GCP) |
| :--- | :--- | :--- | :--- |
| **Compute** | Amazon EC2 | Azure Virtual Machines | Google Compute Engine |
| **Storage** | Amazon S3 | Azure Blob Storage | Google Cloud Storage |
| **Networking** | Amazon VPC | Azure Virtual Network (VNet) | Virtual Private Cloud (VPC) |
| **Identity and Access Management (IAM)** | AWS IAM | Microsoft Entra ID (formerly Azure AD) | Cloud IAM |

---

## Guide Questions

**1. Which cloud provider offers the broadest range of services? Explain your answer.**
Amazon Web Services (AWS) offers the broadest and deepest range of cloud services. Because it was the first major public cloud platform to launch, it had a significant head start in the market, allowing it to develop a massive ecosystem of specialized tools ranging from basic infrastructure to advanced robotics, IoT, and quantum computing.

**2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?**
I would strongly recommend Microsoft Azure for an organization heavily invested in Microsoft products. Azure provides seamless, native integration with enterprise tools like Windows Server, Office 365, Active Directory (now Entra ID), and the .NET framework, making hybrid cloud deployments and migrations much smoother.

**3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?**
Google Cloud Platform (GCP) is widely recognized as the industry leader in these areas. Because Google originally developed Kubernetes (based on their internal Borg system) and created the TensorFlow machine learning framework, GCP offers highly optimized, first-class managed services for AI, ML, and container orchestration.

**4. What similarities did you observe among the three cloud providers?**
All three major cloud providers offer the exact same foundational Infrastructure as a Service (IaaS) building blocks—compute, storage, and networking—just packaged under different brand names. Additionally, they all use a pay-as-you-go pricing model and rely on robust Identity and Access Management (IAM) systems to secure user access.
