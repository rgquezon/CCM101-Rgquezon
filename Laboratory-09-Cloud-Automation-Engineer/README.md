# Mission 9: The Cloud Automation Engineer

## Mission Overview
Automated a critical data backup process using Bash scripting and scheduled it to run autonomously using the Linux Cron scheduler, eliminating the risk of human error in routine cloud operations.

## Objectives
* Write and format a functional Bash script using the nano text editor.
* Modify file permissions using `chmod` to allow script execution.
* Automate directory creation and file compression using a script.
* Configure the Linux crontab to schedule recurring tasks based on time parameters.

## Commands Executed
* `mkdir app-data`
* `nano backup.sh`
* `chmod +x backup.sh`
* `./backup.sh`
* `crontab -l`
* `env EDITOR=nano crontab -e`

## Skills Learned
* Bash shell scripting and variable utilization.
* Linux file permission management (chmod).
* Task scheduling and automation using Cron.
