# Mission 6: The Cloud Deployment Engineer

## Mission Overview
Deployed a multi-tier private cloud storage application using Nextcloud and MariaDB orchestrated with Docker Compose as Infrastructure as Code (IaC).

## Objectives
* Understand multi-tier application architecture and service isolation.
* Create and structure a valid `docker-compose.yml` YAML configuration file.
* Orchestrate multi-container stack deployment, verification, and teardown using Docker Compose CLI.
* Document Infrastructure as Code (IaC) principles and service discovery mechanics.

## Commands Executed
* `mkdir nextcloud-deployment && cd nextcloud-deployment`
* `nano docker-compose.yml`
* `docker-compose up -d`
* `docker-compose ps`
* `docker-compose down`

## Skills Learned
* Multi-tier container orchestration using Docker Compose.
* YAML configuration syntax and environment variable handling.
* Docker internal DNS service discovery.
* Managing enterprise private cloud software stacks.
