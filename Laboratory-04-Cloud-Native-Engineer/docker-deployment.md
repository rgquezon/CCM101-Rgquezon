1. `docker ps`
   * **Explanation:** Lists all active, running containers along with their container IDs, assigned names, and active port mappings.
2. `docker stop my-nginx`
   * **Explanation:** Gracefully halts the execution of the running `my-nginx` container process without deleting its filesystem[cite: 1].
3. `docker ps -a`
   * **Explanation:** Displays all containers on the local system, including active running containers and stopped containers[cite: 1].
4. `docker rm my-nginx`
   * **Explanation:** Permanently deletes the stopped `my-nginx` container instance and releases its allocated system resources[cite: 1].
